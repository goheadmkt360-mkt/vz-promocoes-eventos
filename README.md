# VZ Promoções e Eventos

Site institucional estático da VZ Promoções e Eventos.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: identidade visual, animação do símbolo e layout responsivo.
- `script.js`: menu de navegação mobile e formulário que prepara uma mensagem no aplicativo de e-mail do visitante.
- `assets/vz-simbolo-oficial.svg`: símbolo VZ do pacote de marca.
- `assets/evento-ilustrativo-temporario.png`: fotografia genérica de apoio, a ser substituída por registro próprio autorizado.

O site não armazena os dados do formulário. Ao clicar em Enviar, o aplicativo de e-mail do visitante é aberto com a mensagem preenchida para revisão e envio. A página não publica datas, local ou informações de eventos antes da realização.

## Publicação

Projeto preparado para hospedagem estática pelo GitHub Pages e domínio `www.vzpromocoeseventos.com.br`.
